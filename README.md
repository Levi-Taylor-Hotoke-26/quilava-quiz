# Quilava Quiz

![Quilava Quiz screenshot](https://github.com/user-attachments/assets/b21a928e-2423-42e9-8617-4bbab1769151)

Quilava Quiz is a browser-based Pokémon trivia game built with vanilla HTML, CSS, and JavaScript.  
Answer questions correctly to gain experience, evolve from **Cyndaquil → Quilava → Typhlosion**, and collect all **8 Kanto Gym Badges**.

## Features

- 40-question quiz run with randomized picks from themed question banks
- Image-based prompts for Pokémon, locations, items, badges, and more
- Experience system (+100 XP per correct answer)
- Evolution milestones:
  - 17 correct answers: Cyndaquil evolves into Quilava
  - 40 correct answers: Quilava evolves into Typhlosion
- Badge tracker that awards 1 badge every 5 correct answers
- Feedback messages and celebration audio on evolutions

## Tech Stack

- HTML
- CSS
- JavaScript (no frameworks)

## Getting Started

1. Clone the repository.
2. Open `/home/runner/work/quilava-quiz/quilava-quiz/index.html` in your browser.

No build step or package installation is required.

## How to Play

1. Read the question prompt and image.
2. Type your answer in the input field.
3. Submit to check correctness.
4. Keep answering correctly to gain XP, evolve, and earn gym badges.
5. Complete all 40 questions to finish the run.
